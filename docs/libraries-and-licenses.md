## ٣. الملفات الصوتية والرسومية
- **ملفات الصوت (`public/audio/adhan-alert.wav`, `soft-bell.wav`, `focus-bell.wav`):** نغمات مركبة محلياً ومملوكة للمشروع بالكامل (لا تتبع أي جهة خارجية).
- **الأيقونات (`src/components/icons.js`, `public/icons/jawoo.svg`):** رسوم SVG أصلية خفيفة مدمجة داخل المشروع.

## ٤. مصادر البيانات الخارجية
- **مواقيت الصلاة:** واجهة AlAdhan API (طريقة الهيئة المصرية العامة للمساحة `method=5`) مع بديل فلكي محلي مؤقت عند غياب البيانات المخزنة.
- **الطقس:** واجهة Open-Meteo العامة دون مفاتيح سرية، مع تخزين آخر قراءة وعرض حالتها عند الانقطاع.
- **المحتوى الديني:** نصوص قرآنية برواية حفص، وتفسير موجز مستفاد من التفسير الميسر (مجمع الملك فهد)، وأحاديث من صحيحي البخاري ومسلم بأرقامها وتخريجها.

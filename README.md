# جووو — لوحة التشغيل اليومية العربية لشاشة التلفاز

لوحة تشغيل يومية متكاملة باللغة العربية (`RTL`)، مصممة في وضع فاتح دافئ يسهل قراءته من مسافة المشاهدة، مع تحكم كامل بأسهم ريموت التلفاز وزر التأكيد والرجوع، وعمل موثوق عند انقطاع الإنترنت.

---

## ١. هيكل المشروع

## ٢. التشغيل والاختبار والبناء (Windows PowerShell)

> ملاحظة: على Windows قد يمنع PowerShell تنفيذ `npm.ps1`؛ استخدم `npm.cmd` مباشرة.

- **تشغيل بيئة التطوير (مع إتاحة الشبكة المحلية لاختبار التلفاز):**
  ```powershell
  npm.cmd run dev -- --host
  ```
- **تشغيل جميع الاختبارات:**
  ```powershell
  npm.cmd test
  ```
- **بناء نسخة الإنتاج (`dist/`):**
  ```powershell
  npm.cmd run build
  ```
- **معاينة نسخة الإنتاج على الشبكة المحلية لفتحها من التلفاز:**
  ```powershell
  npm.cmd run preview
  ```

## ٣. النشر المقترح وطريقة التراجع (الإصدار الأول: Vercel)

1. ارفع المشروع إلى مستودع Git (أو استخدم `vercel --prod` عبر Vercel CLI).
2. إعدادات البناء الثابتة في Vercel:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
3. **طريقة التراجع عند ظهور مشكلة:**
   - من لوحة تحكم Vercel (`Deployments`) اختر آخر إصدار مستقر ثم **Promote to Production** فوراً.
   - في النسخ المحلية، احتفظ بوسم إصدار (`git tag v1.0.0`) وصدّر نسخة احتياطية JSON من صفحة **الإعدادات** قبل أي تحديث كبير.

## ٤. الاختبار الإلزامي على تلفاز توشيبا (المرحلة صفر)

1. افتح رابط المعاينة على متصفح تلفاز توشيبا، ثم انتقل إلى صفحة **فحص التلفاز** من الشريط السفلي.
2. فعّل **«إظهار إطار الأمان ٤٪»** للتحقق من عدم قص أي جزء من الشاشة.
3. اضغط زر **«اختبار تشغيل الصوت»** ثم اختبر أزرار الريموت (الأسهم، التأكيد، الرجوع) وراقب قراءة الأكواد في سجل الاختبار الحي.
4. سجّل النتائج الفعلية في [tv-test-report-template.md](./docs/tv-test-report-template.md) قبل اعتماد التشغيل الدائم.
